# Raspberry-pi-pico-pong
A work in progress to make pong playable on a raspbery pi pico with a matrix 8x8 led screen

A small game project using a Raspberry Pi Pico W and MicroPython.

## Hardware
- Raspberry Pi Pico W (RP2040)
- MAX7219 8×8 LED matrix
- SPI communication

## Goal
Build a simple game, starting with Pong or Breakout, while learning MicroPython and basic game development.

## Status
Made a simple button testing script. working on main loop.
